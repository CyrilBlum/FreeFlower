\section{Mikrocontroller und Arduino}
In diesem Kurs arbeiten Sie mit Arduino, einer einfach zugänglichen Mikrocontroller-Plattform. Ein \emph{Mikrocontroller} ist ein kleiner Computer, der elektronische Komponenten steuern und auf seine Umgebung reagieren kann. Damit lassen sich beispielsweise LEDs schalten, Motoren bewegen und Sensoren auslesen.

Arduino wurde ursprünglich am Interaction Design Institute Ivrea in Italien entwickelt. Die Plattform richtet sich deshalb nicht nur an Fachpersonen aus Elektrotechnik und Informatik, sondern ermöglicht auch Einsteigerinnen und Einsteigern einen schnellen Zugang zu interaktiven Projekten. Eine kleine Auswahl möglicher Anwendungen finden Sie über \href{https://youtu.be/5hYFX2mDNAY?is=9WRy6nbNgjXifvhV}{diesen Links} oder über den QR-Code:
\begin{center}
    \qrcode[height=2.6cm]{https://youtu.be/5hYFX2mDNAY?is=9WRy6nbNgjXifvhV}
\end{center}

Eine Arduino-Anwendung besteht aus zwei eng zusammenarbeitenden Teilen:
\begin{itemize}
	\item \textbf{Hardware:} Das Input-Output-Board verbindet den Mikrocontroller über seine Pins mit Tastern, Sensoren, LEDs, Displays oder Motoren.
	\item \textbf{Software:} Ein Programm legt fest, wie das Board Eingaben verarbeitet und seine Ausgänge steuert. Arduino-Programme basieren auf C und C++.
\end{itemize}

Die Pins eines Arduino können unterschiedliche Aufgaben übernehmen. Digitale Pins verarbeiten zwei logische Zustände, analoge Eingänge messen eine Spannung innerhalb eines bestimmten Bereichs. Einzelne digitale Pins können zudem ein PWM-Signal ausgeben. Diese Funktionen werden in den folgenden Kapiteln schrittweise eingeführt.

\section{Schaltungen auf dem Breadboard}
Für Versuchsaufbauten wird meist eine Steckplatine verwendet, auf Englisch \emph{Breadboard}. Bauteile und Kabel können eingesteckt und ohne Löten zu einer Schaltung verbunden werden. \Cref{fig:breadboard-circuit} zeigt einen typischen Aufbau.

Bei den in diesem Kurs verwendeten Breadboards sind jeweils fünf übereinanderliegende Kontakte innerhalb eines Anschlussstreifens elektrisch verbunden. Die beiden Gruppen auf jeder Seite des mittleren Grabens sind voneinander getrennt. Die mit $+$ und $-$ gekennzeichneten Versorgungsleisten verlaufen dagegen in Längsrichtung; bei manchen Breadboards sind diese Leisten in der Mitte unterbrochen.

Die Anschlüsse eines Bauteils müssen in unterschiedliche Kontaktgruppen gesteckt werden. Werden beispielsweise beide Beine einer LED in dieselbe Fünfergruppe gesteckt, liegen sie am selben elektrischen Knoten und es kann keine Spannung über der LED entstehen.

\section{Aufbau eines Arduino-Programms}
Ein Arduino-Programm wird als \emph{Sketch} bezeichnet. Jeder Sketch besitzt normalerweise die beiden Funktionen \cppinline{setup()} und \cppinline{loop()}:
\begin{itemize}
	\item \cppinline{setup()} wird nach dem Einschalten oder Zurücksetzen des Boards genau einmal ausgeführt. Hier werden beispielsweise Pinmodi, Variablen, Bibliotheken und Kommunikationsschnittstellen initialisiert.
	\item \cppinline{loop()} wird anschliessend fortlaufend wiederholt. In dieser Endlosschleife liest das Programm Eingaben ein, verarbeitet Daten und steuert Ausgänge.
\end{itemize}

\begin{lstlisting}[
	language=C++,
	morekeywords={setup,loop,pinMode,digitalWrite,delay},
	columns=fullflexible,
	keepspaces=true,
	breaklines=false,
	showstringspaces=false,
	basicstyle=\ttfamily\footnotesize,
	caption={Grundstruktur eines Arduino-Sketches},
	label={lst:arduino-sketch-structure}
]
const int ledPin = 9;

void setup()
{
  pinMode(ledPin, OUTPUT);
}

void loop()
{
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}
\end{lstlisting}

\section{Praktisches Einführungsbeispiel}
In einem ersten Projekt wird eine Schaltung aus einem Taster und mehreren LEDs aufgebaut. Beim Betätigen des Tasters verändert das Arduino-Board die leuchtenden LEDs. Dadurch lernen Sie das Breadboard, digitale Ein- und Ausgänge sowie das Übertragen eines Sketches kennen.

\subsection{Material}
\begin{itemize}
	\item Arduino Uno und USB-Kabel
	\item Breadboard und Verbindungskabel
	\item ein Taster
	\item sechs LEDs: vier rote, eine grüne und eine gelbe LED
	\item sechs Vorwiderstände zu je \qty{220}{\ohm}
	\item ein Widerstand mit \qty{10}{\kilo\ohm}, beispielsweise als Pull-down-Widerstand für den Taster
\end{itemize}

\subsection{LEDs sicher verwenden}
\begin{myattention}
Eine LED darf nicht ohne Vorwiderstand an einen Arduino-Pin oder eine Spannungsquelle angeschlossen werden. Ohne Strombegrenzung können sowohl die LED als auch der Ausgang des Mikrocontrollers beschädigt werden.
\end{myattention}

Der benötigte Widerstand hängt von der Versorgungsspannung, der Durchlassspannung der LED und dem gewünschten Strom ab. Widerstandswerte können mithilfe der aufgedruckten Farbringe bestimmt werden; \cref{fig:resistor-colour-code} zeigt das Prinzip.

\begin{figure}[ht]
	\centering
	\includegraphics[width=.58\textwidth]{FF/Robotik/Skript/Abbildungen/Farbcodes_Wiederstaende.png}
	\caption{Farbcodierung von Widerständen.}
	\label{fig:resistor-colour-code}
\end{figure}

LEDs müssen ausserdem richtig gepolt werden. Die Anode wird mit dem positiveren Potential, die Kathode mit \texttt{GND} verbunden. Bei bedrahteten LEDs ist die Anode meist am längeren Bein erkennbar. Das kürzere Bein und die abgeflachte Seite des Gehäuses kennzeichnen in der Regel die Kathode.

\section{Lichtabhängige Steuerung}
Ein Fotowiderstand, auch LDR (\emph{Light Dependent Resistor}) genannt, verändert seinen elektrischen Widerstand abhängig von der Beleuchtungsstärke. Typischerweise ist sein Widerstand im Dunkeln gross und bei hellem Licht klein. Da das Arduino-Board einen Widerstand nicht direkt misst, wird der LDR zusammen mit einem festen Widerstand als Spannungsteiler zwischen \qty{5}{\volt} und \texttt{GND} geschaltet. Der Verbindungspunkt beider Widerstände wird mit dem analogen Eingang \texttt{A0} verbunden.

Ist der LDR zwischen \qty{5}{\volt} und \texttt{A0} angeordnet, steigt die an \texttt{A0} gemessene Spannung bei zunehmender Helligkeit. Der ADC wandelt diese Spannung in einen digitalen Wert zwischen $0$ und $1023$ um. Die genaue Zuordnung hängt von den Widerstandswerten und der tatsächlichen Referenzspannung ab.

\begin{lstlisting}[
	language=C++,
	morekeywords={setup,loop,pinMode,analogRead,digitalWrite,delay,Serial},
	columns=fullflexible,
	keepspaces=true,
	breaklines=false,
	showstringspaces=false,
	basicstyle=\ttfamily\footnotesize,
	caption={Beispiel zum Auslesen eines Fotowiderstands},
	label={lst:ldr-example-code}
]
const int ldrPin = A0;
const int ledPin = 13;
const int threshold = 512;

void setup()
{
  Serial.begin(9600);
  pinMode(ledPin, OUTPUT);
}

void loop()
{
  int sensorValue = analogRead(ldrPin);
  Serial.println(sensorValue);

  if (sensorValue > threshold) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }

  delay(50);
}
\end{lstlisting}
